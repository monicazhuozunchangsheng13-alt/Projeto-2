Front-End

Exemplo de página técnica para explicar as tecnologias estudadas e registrar evidências de prática.

HTML

Organiza a estrutura e o significado do conteúdo da página.

<h1>Meu projeto</h1>

CSS

Controla cores, tipografia, espaçamento e layout.

.card { padding: 16px; }

JavaScript

Adiciona comportamento e interatividade aos elementos.

botao.addEventListener("click", ...);

Meu exercício

Durante as aulas, criei várias páginas de prática em HTML e CSS — como index, Exemplos, tabela, pesquisa e menu — para consolidar os fundamentos do desenvolvimento front-end. Utilizei elementos estruturais e de texto, listas ordenadas e não ordenadas imagens, formulários e menus de navegação com hiperligações. Também apliquei estilos com CSS interno e externo para trabalhar cores, tipografia, espaçamentos, esquemas de cores e menus dropdown. Com esta prática, aprendi a estruturar páginas web de forma organizada, a ligar diferentes ficheiros e a ter atenção a detalhes como a sintaxe das etiquetas, os caminhos dos ficheiros e a ordem das regras CSS. Tambem outro arqivo onde o professor mandou os exemplos básicos de JavaScript para demonstrar a lógica de programação e a interatividade nas páginas web. Os códigos abordaram alertas, entrada de dados, funções com e sem parâmetros, variáveis, operadores matemáticos, estruturas condicionais, laços de repetição, vetores, objetos e manipulação do DOM. Acompanhar estes exemplos do professor ajudou-me a compreender como o JavaScript dá comportamento dinâmico às páginas e como ligar o código ao HTML.
